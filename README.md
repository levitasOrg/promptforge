# PromptForge

> Turn vague prompts into structured, token-efficient prompts — from your terminal.

**Status: Phase 1 (skeleton) — commands print "not implemented".** See `docs/plan-promptforge-v4.md` for the full design.

## Requirements
- Python 3.11+
- macOS or Linux (including WSL). Native Windows is not supported.

## Install (dev)
```bash
pip install -e ".[dev]"
```

Full user-facing README is generated in Phase 7 per § 17 of the plan.
